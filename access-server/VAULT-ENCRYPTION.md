# 私密空间的云端加密

范围：仅私密空间的照片、文件、日记、自慰记录、个人目标及其文件名/标题。普通学习资料和个人账户不在本次加密范围。

## 启用

进入个人模式 → 私密空间 → 输入一次至少10位的私密空间密码，同时完成入口验证与本机解密。
首次启用加密直接使用这次密码，无需再次设置或输入第二个密码。密码在页面内存中短暂使用，不会保存在 localStorage、IndexedDB 或 Cookie。
若旧版已经设置了不同的入口密码和加密密码，只需一次兼容验证，之后以原加密密码作为统一密码。页面关闭或刷新后仍需重新解锁。
首次页面生成离线恢复 JSON 文件。必须下载并选回文件核验，勾选已妥善保存，才可开始迁移。

迁移逐个读取旧附件，使用 Web Crypto AES-256-GCM 分块加密并以随机文件名上传，读回解密并比较 SHA-256。
私密记录以 AES-GCM 加密 JSON 保存。文件字节不会转成 JSON Base64；只有小型记录密文及包裹后的密钥是 Base64。
所有附件和记录验证完成后，才提交一个新版本的快照。遇到冲突返回409，不覆盖其他设备的更新。

**旧明文原件、历史云盘快照、先前导出的本地备份不会自动删除。**
所以“新记录已加密”不等于“所有历史资料彻底加密”。页面持续显示提醒，清理须在启用、跨设备恢复和完整性核验后另行执行。
Google Drive 中的大小、上传时间、随机ID及文件数量仍可见。

## 密钥和恢复

随机256位主密钥仅在浏览器内存使用，以600000次 PBKDF2-SHA256 从密码派生的密钥包裹。
独立随机256位恢复密钥包裹同一个主密钥。恢复文件等同于访问钥匙，应离线保管，避免与同一云盘放在一起。
AES-GCM 每次使用随机96位IV和用途/文件ID/分块序号作为AAD；验证失败、截断、错文件均拒绝读取。

忘记密码：先通过 Google 所有者验证进入个人模式，然后打开 `/private-recovery`，选择离线恢复文件，设置新密码。
恢复页面先在本机解包主密钥并验证记录；服务端只校验域分离的恢复证明摘要，不接收恢复密钥或主密钥。
新密码用于更新入口密码和包裹主密钥的加密密码，旧授权立即失效。并发更新会拒绝恢复，需要重新加载再试。
恢复文件和密码全部丢失时，无法解密新密文；后台重置入口密码不等于恢复加密资料。
尚未启用加密的入口密码无法用此文件恢复。

## 保护边界与维护

这是浏览器端加密，对持有云盘文件但没有密码/恢复文件者保护当前密文。
不防已被控制的设备、浏览器扩展或被恶意替换的网页脚本；运行页面的代码及发布账号仍需可信。
打开、下载和主动导出备份时，会在本机产生明文。导出前显示提醒。私密附件解密不写入 IndexedDB。
私密文件暂先下载完整密文 Blob 后逐块解密再预览，250 MiB上限保留；普通教材的按需读取保持原样。
普通个人模式不能获取密文配置，普通保存必须原封不动保留密文；访客无任何私密接口权限。
加密启用后，旧版明文快照读取和覆盖接口停用；拒绝旧客户端从私密页面继续明文保存。
恢复程序仅更换密钥包裹和入口密码，不重新加密附件或删除资料。

代码验证：`node test-vault-core.mjs`、`node test-private-password.mjs`、`node test-migration.mjs`、原权限及私密空间回归测试。
参考：[Web Crypto encrypt](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt)、[deriveKey](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey)。
