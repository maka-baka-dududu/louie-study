# Louie 的小站：线上运行说明

唯一使用入口：https://louie-study-access.louie-zhuo-lv.workers.dev/

- 访客模式：访客密码，可查看允许的内容，配色仅保存于自己的浏览器。
- 个人模式：独立密码与指定 Google 账号验证，可编辑和上传。
- 个人账户、关联记录、附件及智能问答由服务端隔离，不下发给访客。
- 旧 GitHub Pages 首页只负责跳转；通用地图与编程运行组件仍作为静态资源托管，不需要本地服务器。
- 学习数据、附件、问答快照保存在私人 Google Drive。每次保存产生新快照，旧版本留作回滚。
- 问答对话、问题本、长期记忆、教学规则已移至线上；使用原有 DeepSeek API。
- 浏览器中的 Python/C++ 练习、录音、播放和缓存仍使用设备能力，均不需要运行本地网站。

## 授权和密钥

Google OAuth 项目必须为正式版，授权范围为 `drive.file`；回调为网站 `/auth/owner/callback`。代码验证 Google 账号身份后才建立个人模式。

首次正式授权取得的长期刷新令牌保存在 Durable Object 中，并由 `SESSION_SECRET` 派生的 AES-GCM 密钥加密。DeepSeek 密钥也加密存于服务端。前端和备份不会拿到这些密钥。不要随意更换 `SESSION_SECRET`，否则需要重新连接授权和 API。

部署时的必需 secrets：`READ_VERIFIER`、`EDIT_VERIFIER`、`SESSION_SECRET`、`GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`DRIVE_ROOT_ID`、`DRIVE_REFRESH_TOKEN`（初始迁移/回滚用途）。线上取得的新长期授权优先于初始令牌。

仓库不保存真实凭证。不要把 `secrets.local.json`、授权配置目录、浏览器 Cookie、私人备份或迁移报告复制进仓库。

## 维护和恢复

`wrangler.jsonc` 为免费 Worker 配置，`ASSET_COMMIT` 指向已推送的前端提交。修改代码后先推送，再将该值设为新提交并部署。不得开启付费服务来绕过额度限制。

每日北京时间 09:15 在云端检查 Drive 连接，记录上次成功时间；不会调用收费 AI 或依赖个人电脑。个人模式的 `/api/system/status` 可查询，`POST /api/system/check` 可手动核验。

个人模式右上角“存储容量”读取 Google 真实额度，达到 90% 提醒。单文件 250 MiB，采用分块可恢复上传。DeepSeek 费用取决于已有 API 账户余额及用量。

免费托管不代表永久 SLA；Google 授权撤销、账号异常、Drive 空间不足、DeepSeek 余额不足及服务商故障仍需处理。若 Drive 需重连，在个人模式“存储容量”中更新长期授权。

本次迁移未删除本地原始记录。旧公开文件已从当前 Pages 部署移除，Git 历史和外部缓存不因普通删除提交而自动清除；如需追溯清理，应先备份并单独评估历史重写及缓存清理。

已安装官方 Wrangler 并登录时，可在推送代码后执行 `node access-server/deploy.mjs`。它使用当前 Git 提交覆盖 `ASSET_COMMIT`，不会读取或打印凭证，也不会把密钥放进命令参数。


## 手动考研信息更新

个人模式在“成长星轨 → 考研 → 报考设置”填写学校、专业，可选填学院和招生年份。随后在“考研信息”点击“更新信息”。访客只能读取已保存结果，服务端拒绝访客触发搜索、整理或其他 AI 接口。

服务端使用现有 DeepSeek 的 Search/Fetch API 搜索并打开官方原文，再提取有逐字依据的事实。范围限定为学校/科研院所、教育部和研招网的官方 HTTPS 来源；不可读网页、目录附件不完整、没有原文依据的日期/分数保留待核实。复试线与拟录取最低初试分分开；本功能不会自动推算录取最低分。

数据按学校、学院、专业和明确的招生年份分别存储于私人 Drive；未填年份不会推定。更新失败保留旧结果和核验日期。旧快照和更正历史保留。网页查看和每日连接自检不会调用付费 AI；手动更新会使用已有 DeepSeek 账户的搜索及模型用量。

网页奶蛙复用现有 `/api/teacher?projectId=…` 记录，按当前项目切换。首页和分类页先选项目，避免默认串入考研。打开面板只读取当前项目历史，不发起模型请求；点历史记录后进入原问答，资料、问题本与记忆仍由既有项目隔离管理。访客只有静音形象和收起操作，不读问答。网页不导入或公开桌面、QQ、微信的聊天记录。形象使用原定制桌宠静态素材，点击有轻微形变，无音频和语音权限。

个人账户现在在每条资产、账目、攒钱计划和预算表单内选择币种，列表保留原币金额。总览与资产比例统一按参考汇率折算成人民币，攒钱存入不重复计作支出；归档资产不计入当前总资产。总览按当前自然月统计，历史月份选择只作用于收支账本。资产和计划的原有日期数据保留，但不再展示或要求填写。

`GET /api/finance/rates` 仅个人模式可读，从 Frankfurter 的 ECB 参考汇率接口查询固定币种集合（不发送余额、姓名或账目），六小时缓存，显示原始发布日期。它是最新可得的每日参考价，不是实时成交价。源站失败时明确标注使用上次缓存；没有可用汇率时不把不完整的外币合计显示成总资产。原始资产金额不会因汇率变化被改写，无新增收费服务或 API 密钥。

资产趋势使用 `personal.finance.history` 保存每日快照（原币总额、人民币估值和汇率日期），与学习数据一起私有同步和备份。在打开资产总览或修改账户数据时记录，同日更新该日最后一笔，历史日期不回算、不凭旧收支虚构历史余额，未访问的日期不补点。缺汇率时保留原币快照并留空估值，取得汇率后仅补当天；保存失败回退，账户修改串行执行。支持 7/30/90 天及全部视图，首次仅显示真实的起始点。

网页奶蛙现在无下方文字标签，单击直接进入当前项目的原问答，双击只在当前浏览器隐藏；“设置 → 显示奶蛙”可恢复。未进入项目时单击先选项目，访客仍不能读取问答或调用 AI。单击动作延迟少许以区分双击；保持静音。

移动端布局使用 `private-ui/responsive-ui.js`，按可用宽度适配：900px 以下为顶部菜单和可收起抽屉，选择页面、点击空白处或 Esc 关闭；只维护当前设备的显示状态，不改桌面折叠偏好或任何学习记录。小屏卡片/表单按列重排，表格仅在自身区域滚动，输入框避免过小，问答/地图按动态可用高度布局，并考虑安全区域和输入键盘。趋势图在宽度变化时单独重绘，不重建提问表单或丢失草稿。首次加载即包含小屏样式，动态模块就绪后维持一致布局。旅行日记的表单、文字与触控目标有独立的小屏样式，原地图数据和加载方式不变。

布局验证：320×740、390×844、768×1024、844×390、1024×768、1440×900 等浏览器视口；检查了首页、抽屉菜单、项目、个人账户/趋势、资产弹窗、问答输入、地球、旅行日记与行程抽屉。测试数据仅在本机内存预览，未上传至个人资产账户。访客权限保持服务端校验。
